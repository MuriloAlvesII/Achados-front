# Como Executa

Clone o repositório:
```bash
  git clone http//link.do.repossitorio
```
Entre na pasta do projeto:
```bash
  cd Nome-Projeto

```
Instale as dependências:
```bash
  npm install
```
Execute o projeto:
```bash
  npm run dev
```
Depois, acesse o endereço mostrado pelo Vite no terminal.
