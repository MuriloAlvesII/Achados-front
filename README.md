# Inventum

## Objetivo

O objetivo deste projeto é desenvolver um sistema web de achados e perdidos para o IFRN – Campus Pau dos Ferros e integrá-lo à API disponibilizada pelo professor Jeferson Queiroga.

O projeto serve como prática dos conceitos de desenvolvimento de aplicações web com React e da integração entre uma interface web e uma API.

## Como Executa

É necessário ter o **Node.js** e o **npm** instalados.

Clone o repositório:

```bash
git clone https://github.com/MuriloAlvesII/Inventum-IF.git
```

Entre na pasta do projeto:

```bash
cd Inventum-IF
```

Instale as dependências:

```bash
npm install
```

Configure as variáveis de ambiente necessárias no arquivo `.env`, conforme a configuração da API utilizada pelo projeto. Não compartilhe chaves de API publicamente.

Execute o projeto:

```bash
npm run dev
```

Depois, acesse no navegador o endereço mostrado pelo Vite no terminal, normalmente `http://localhost:5173`.
