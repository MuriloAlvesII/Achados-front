# Inventum

## Objetivo

O **Inventum** é uma aplicação web de achados e perdidos desenvolvida para o campus do IFRN – Campus Pau dos Ferros. O sistema permite consultar itens encontrados, pesquisar e filtrar registros por nome, status, categoria e local, além de cadastrar novos itens e visualizar seus detalhes. A proposta é facilitar a devolução dos objetos aos seus donos e ajudar a comunidade acadêmica a encontrar itens perdidos.

## Como Executa

É necessário ter o **Node.js** e o **npm** instalados.

Clone o repositório:

```bash
git clone https://github.com/MuriloAlvesII/Inventum-IF.git
```

Entre na pasta do projeto:

```bash
cd Inventum-IF
```

Instale as dependências:

```bash
npm install
```

Configure as variáveis de ambiente necessárias no arquivo `.env`, conforme a configuração da API utilizada pelo projeto. Não compartilhe chaves de API publicamente.

Execute o projeto:

```bash
npm run dev
```

Depois, acesse no navegador o endereço mostrado pelo Vite no terminal, normalmente `http://localhost:5173`.
